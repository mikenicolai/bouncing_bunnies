# Shaft crystals and pit edges

Created with the built-in ImageGen tool, using the existing ground paintings as style references. Original RGBA outputs are preserved, including their transparent backgrounds.

`volcano-shaft-crystals-v1.png` is a horizontal crystal hazard, mirrored on alternate sides of the volcano descent. `grassy-pit-edge-v1.png` paints meadow and forest boundaries; `sandy-pit-edge-v1.png` paints shoreline boundaries. Fire pits reuse `ember-cliff-edge-v1.png`. Runtime corners are cropped and mirrored from complete paintings.
