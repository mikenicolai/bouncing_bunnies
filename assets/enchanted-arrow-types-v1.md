# Normal, fire and rainbow arrows

Generated with the built-in ImageGen tool using a true transparent background. Original PNG copied unchanged to `assets/enchanted-arrow-types-v1.png` (2172 × 724). Three equal square cells, left to right: normal, fire, rainbow. The runtime uses these cells in the five-arrow inventory, pickup and projectiles. Existing bow and bunny artwork is retained.

Normal arrows deal one heart (89%), fire arrows two hearts (10%), rainbow arrows three hearts (1%). Each initial and returned arrow is rolled independently. One spent slot refills every three seconds of active play, even while the bow is stowed. New Fire runs choose a reachable maze pickup location different from the previous run; checkpoints preserve it.
