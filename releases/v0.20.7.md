# v0.20.7 — Blended pond banks and clear coin accounting

Meadow’s pond banks now blend sand into rooted soil along an irregular boundary. Overlapping, staggered texture patches continue through the full ground depth, removing sharp vertical material seams and blank brown areas on tall displays.

The HUD labels the spendable wallet as “available” and the level count as “collected.” A per-run equation shows the starting wallet, collected coins and coins spent on hearts. For example, 0 + 30 collected − 20 spent leaves 10 available. New runs start the equation with the existing wallet; free test ads do not spend coins. The map shows the same accounting.

Direct-file Meadow play uses the existing sprite’s registered bounds instead of reading blocked canvas pixels, preserving the zombie artwork while avoiding an animation-stopping error.
