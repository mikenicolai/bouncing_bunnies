# v0.22.0 · Adventure release

Build 2026110101 · 1 November 2026.

The production game disables the hidden map shortcut and all developer coin/level entry functions. The developer panel and its inputs/buttons are removed from the running page. Normal progression, replay, wallets and revives are retained. The obsolete R-reset hint is removed. Test fixtures can enable development tools in memory; the release has no URL or storage opt-in.

## Validation

- Production browser coverage: no developer controls or D shortcut; no developer coin/level grants, including with URL flags; desktop/portrait/landscape map; paid checkpoint continuation, actual five-second restart, saving, ordered unlocks and replay; no page errors or failed resource requests.
- Unit coverage: developer/save isolation in an explicit QA fixture, mobile controls/layout, wallet/revival and Wildwood fight regression.
- Browser load evidence: `previews/production-release-audit-v0.22.0.json`. A fresh local title load decoded 29,676,717 HTML bytes and 136,031,970 resource bytes, about 158 MiB combined. This is a local uncompressed-load measurement, not a CrazyGames QA result.

## Before CrazyGames submission

1. **Reduce loading weight first.** Compress artwork, remove duplicate embedded/external images, and load later worlds when needed. Initial download must be at most 50 MB, or 20 MB for the mobile homepage. Without SDK integration, the total bundle must meet that limit; with SDK, total files can reach 250 MB. Upload only runtime dependencies, excluding previews, tests, source art and old releases. [Technical requirements](https://docs.crazygames.com/requirements/technical/).
2. **Replace or hide the simulated advertisement.** The current five-second button is still a local test, not advertising. For Basic Launch, disable that offer while retaining the coin/free options. For monetized launch, integrate rewarded ads, grant the restart only on `adFinished`, handle `adError` without a reward, and pause/mute correctly. Basic Launch has ads disabled; real ads must use the SDK. [Ad requirements](https://docs.crazygames.com/requirements/ads/), [rewarded callbacks](https://docs.crazygames.com/sdk/html5-v2/video-ads/).
3. **Integrate platform lifecycle when moving to Full Launch.** Basic Launch allows an optional SDK; Full Launch requires integration. Add SDK initialization and gameplay start/stop events around actual play, menus and ads. Keep local GitHub development and test the upload in the Developer Portal QA tool. [Launch requirements](https://docs.crazygames.com/requirements/intro/).
4. **Complete a real-device pass.** Check iPhone/iPad Safari, Android, Chrome/Edge and a low-memory Chromebook, small host iframes, touch controls, audio interruptions and focus changes. The current visibility/blur hooks clear input but do not explicitly pause gameplay or resume an interrupted AudioContext. Also verify 144/165 Hz play, full runs through all worlds, death/reload, coin accounting and the ending. [Gameplay requirements](https://docs.crazygames.com/requirements/gameplay/), [technical requirements](https://docs.crazygames.com/requirements/technical/).
5. **Prepare the submission materials.** Add the English description, controls, covers and video requested by the portal, confirm asset provenance, then use the portal's QA preview before submitting. [Submission overview](https://docs.crazygames.com/requirements/intro/).

The release removes the developer mode as requested. The SDK and advertisement simulation are intentionally listed as follow-up work, not presented as already integrated. No CrazyGames upload or submission was performed.
