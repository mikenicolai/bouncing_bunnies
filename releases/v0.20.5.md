# v0.20.5 — Ordered progression and developer mode

Build 2026101302 · 13 October 2026.

- Normal play progresses through First Meadow, Air, Water, Earth, Fire and the Castle opening. The map painting is informational; its play action offers the next level. Paused runs can still be resumed.
- Press D only while on the map to open a plain developer screen. The shortcut is not advertised in the normal game interface.
- Developer mode lists all six playable destinations, version/build/date, a 0–1,000 test-wallet input and quick 100/1,000-coin buttons.
- Developer coins and victories do not change saved normal progress. Returning to the normal map restores the normal wallet; reloading leaves developer mode.
- `DEVELOPER_TOOLS_ENABLED=false` removes the shortcut and test entry points for production. Existing practice pages use the explicit developer-session helper.

Checks cover ordered progression and reload, locked starts, every test level, test-wallet boundaries and isolation, normal return, real keyboard/buttons, phone layouts and the disabled production flag.
